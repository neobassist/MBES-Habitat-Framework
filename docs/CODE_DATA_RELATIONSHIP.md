# Code and data relationship

The GitHub package contains the reproducibility code snapshot and public-safe MER configuration for `Machine-learning prediction of marine vegetated habitats using multibeam echosounder-derived environmental features`. The accompanying KIOST package contains the derived CSV source data used to verify the manuscript and supplementary figures, tables, validation results, candidate selection, feature importance, and map summaries.

Raw MBES survey rasters, survey-processing projects, expert-reference vector inputs, large derived rasters, samples, and trained model binaries are not included. Consequently, this package supports inspection of the implemented methods and computational reproduction when compatible source inputs are supplied; it does not provide complete independent reproduction from raw survey acquisition.
