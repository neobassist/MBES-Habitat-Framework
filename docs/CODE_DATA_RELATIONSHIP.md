# Code and data relationship

The GitHub repository contains the publication-specific reproducibility code snapshot and public-safe MER configuration for `Machine-learning prediction of marine vegetated habitats using multibeam echosounder-derived environmental features`.

The companion Mendeley Data deposit contains the derived publication source data used to support and verify the manuscript and supplementary figures, tables, validation results, candidate selection, feature importance, and mapping summaries.

Raw MBES survey rasters, survey-processing projects, expert-reference vector inputs, large derived rasters, samples, and trained model binaries are not included. Consequently, this repository supports inspection of the implemented methods and computational reproduction when compatible authorized source inputs are supplied; it does not provide complete independent reproduction from raw survey acquisition.

- GitHub repository: https://github.com/neobassist/MBES-Habitat-Framework
- GitHub release or tag: `v1.0.0`
- Mendeley Data DOI: https://doi.org/10.17632/7dz3gn5zmg.1
