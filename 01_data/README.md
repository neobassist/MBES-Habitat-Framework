# Input data location

Raw scientific data are not distributed with this publication code snapshot.

To run the workflow, place compatible project inputs under `01_data/` using the site and filename structure declared in `02_projects/MER_2026_DB/config_sites.yaml`. Required inputs include frequency-specific bathymetry and FMGT dB backscatter rasters at 200, 300, and 400 kHz, vegetation-reference vectors, and survey-area polygons.

Raw MBES survey data and associated project-level processing files are not publicly included because they form part of ongoing institutional research activities. The accompanying KIOST deposit contains derived publication source data for the manuscript `Machine-learning prediction of marine vegetated habitats using multibeam echosounder-derived environmental features`.
