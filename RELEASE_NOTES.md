# Release notes

Release version and tag: `v1.0.0`

This package is a publication-specific snapshot for the manuscript `Machine-learning prediction of marine vegetated habitats using multibeam echosounder-derived environmental features`. The completed scientific run `run_20260916_035737_2df29152` records source Git commit `cc4fc5f6b1c66bdd60633589c235230acfec6165` and completed successfully on 16 September 2026.

The snapshot contains the authoritative working-tree versions present at package-preparation time of Stages 00–13 and 99, their shared utilities, and the MER configuration. These working-tree versions include publication-maintenance changes made after the recorded source commit. Those changes add common-valid physical-raster exports, optional map previews, cartographic north arrows and scale bars, publication terminology and directory organization, portable metadata, and output-contract checks. They do not retrain the frozen models or change the stored validation predictions, final probability rasters, or candidate AP values used in the manuscript. Stage 13 publication products were regenerated from the stored scientific artifacts.

The internal project compiler, execution history, raw inputs, generated rasters, model binaries, and publication artwork are outside this publication-specific release. Direct stage execution is documented in `README.md`; the companion Mendeley Data deposit supplies the corresponding derived publication source data.
